# Sources and provenance

- REA Investigator, original project and its public documentation: https://github.com/Devaretanmay/rea-investigate . Its 13-capability design, evidence provenance, 4-phase investigation, and strict-audit ideas are integrated **by interface**, not copied as a replacement for its original source. Upstream skill is a separate optional dependency.
- Systemcraft, locally supplied preceding version created for the user in this conversation; templates and scripts `scaffold.py`, `audit.py`, and design/playbook guides were carried forward into Proofwork with the same standard-library requirements.
- Agent Skills open specification (frontmatter, directory conventions, progressive disclosure): https://agentskills.io/specification and https://github.com/agentskills/agentskills/blob/main/docs/specification.mdx .
- Interpretable Context Methodology (folder-oriented agent workflow design): https://arxiv.org/abs/2603.16021 . Inspiration, not a claim of author endorsement.

Proofwork adds original integration instructions, independent evidence/decision/test CLI, installer and its own tests. Code and instructions are not affiliated with or endorsed by any referenced authors or platforms.
